### 🚀 About Me

I'm a Systems Engineer who genuinely loves the craft of building software — not just shipping features, but understanding *why* they work the way they do. I move comfortably across the whole stack: designing a database schema in the morning, wiring up an API in the afternoon, and polishing a UI (web or mobile) by the evening.

I'm the kind of developer who ends up with several repos open at once, because I can't stop learning new tools, frameworks, and patterns. Right now that curiosity is pointed at **game development**, **mobile apps**, and **real-time collaboration tools** — see the projects below, all of them real and in active development.

- 📍 Based in Dosquebradas, Risaralda, Colombia 🇨🇴
- 🎓 Systems Engineering — Fundación Universitaria del Área Andina
- 🎓 Technology in Systems Analysis & Development — SENA
- 🔐 Cisco Networking Academy: Ethical Hacking · CyberOps Associate
- 🌱 Currently sharpening: Next.js, Flutter, React Native, and game dev fundamentals
- 🗣️ English: B1 — I can read docs, write code comments, and hold a technical conversation
- 💬 Ask me about: fullstack architecture, mobile apps, PostgreSQL, or why I think learning never really stops
